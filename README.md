# Parking Lot

Parking Lot is now a small React Native notes app.

## Current App

- `mobile/`: Expo + React Native app
- `expo-sqlite`: local note storage
- Basic CRUD only: create, read, update, delete

## Run It

```bash
cd mobile
cmd.exe /c npm.cmd install
cmd.exe /c npm.cmd run start
```

## View It On Desktop

- Install Android Studio on Windows.
- Create an Android Virtual Device in Device Manager.
- Start the emulator.
- In the Expo terminal, press `a` to open the app in the emulator.

## Notes

- The old web and backend code has been removed from the repo.
- The app is intentionally kept small so only the needed code remains.
